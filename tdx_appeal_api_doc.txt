========================================================================
                      泰迪熊（TDX）二次申诉对接接口文档
========================================================================

一、 接口基本信息
本套接口用于外部直接调用或模拟泰迪熊（TDX）二次申诉清理服务。包含了申诉前置校验、短信验证码获取、验证码提交并执行一键申诉整套业务流程。

* 真实请求基准路径 (Base URL):
  http://47.108.132.88:4300

* 真实身份验证凭证 (Authorization Header):
  为了能够正常访问以下接口，请求的 Header 中必须包含用户在平台登录生成的 Bearer Token，格式如下：
  Authorization: Bearer rc2.eyJ1c2VyIjp7...
  注：Bearer 必须是以 "rc2." 开头

========================================================================

二、 接口定义

------------------------------------------------------------------------
1. 号码状态预检查接口
------------------------------------------------------------------------
* 接口地址: http://47.108.132.88:4300/api/tdx/sms-receive/precheck
* 请求方法: POST
* 数据格式: Content-Type: application/json
* 鉴权头部: Authorization: Bearer [您的SessionToken]

* 请求参数 (JSON Body):
  {
    "phone": "13012345678"   // 必须，待申诉的11位手机号码
  }

* 响应参数 (JSON):
  - 成功响应 (预检通过，允许申诉):
    {
      "success": true,
      "message": "号码预检查通过",
      "data": {
        "ok": true,
        "allowed": true,      // true 代表可以进行下一步申诉
        "status": "可申诉"     // 状态描述
      }
    }

  - 拦截响应 (如：30天内重复申诉或已进入申诉锁定期, HTTP 409):
    {
      "success": false,
      "message": "该号码30天内已申诉过，暂不可重复提交",
      "data": {
        "ok": true,
        "allowed": false,
        "status": "30天内已申诉过"
      }
    }

------------------------------------------------------------------------
2. 发送二次申诉短信验证码接口
------------------------------------------------------------------------
* 接口地址: http://47.108.132.88:4300/api/tdx/sms-receive/send-code
* 请求方法: POST
* 数据格式: Content-Type: application/json
* 鉴权头部: Authorization: Bearer [您的SessionToken]

* 请求参数 (JSON Body):
  {
    "phone": "13012345678",  // 必须，待申诉的11位手机号码
    "line": "line1"          // 可选，通道线路，默认为 "line1"，可选 "line2"
  }

* 响应参数 (JSON):
  - 成功响应:
    {
      "success": true,
      "message": "短信验证码已发起发送",
      "data": {
        "ok": true,
        "line": "line1"
      }
    }

  - 失败响应 (HTTP 502 / 400):
    {
      "success": false,
      "message": "验证码发送失败，请稍后重试。",
      "data": null
    }

------------------------------------------------------------------------
3. 校验验证码并执行二次申诉接口
------------------------------------------------------------------------
* 接口地址: http://47.108.132.88:4300/api/tdx/sms-receive/login
* 请求方法: POST
* 数据格式: Content-Type: application/json
* 鉴权头部: Authorization: Bearer [您的SessionToken]

* 请求参数 (JSON Body):
  {
    "phone": "13012345678",  // 必须，11位手机号码
    "smsCode": "123456",     // 必须，收到的短信验证码
    "line": "line1",         // 可选，通道线路，必须与发送验证码时一致，默认 "line1"
    "rotate": false          // 可选，是否强制重置申诉会话，默认 false
  }

* 响应参数 (JSON):
  - 成功响应 (已成功扣款并在后台拉起一键申诉):
    {
      "success": true,
      "message": "验证码登录验证通过，已开始后台申诉清理",
      "data": {
        "id": 182643,                     // 本次生成的申诉订单 ID
        "phone": "13012345678",
        "orderpicinumber": "TDX2026..."   // 申诉流水号
      }
    }

  - 失败响应 (如：余额不足以支付申诉单价, HTTP 409):
    {
      "success": false,
      "message": "账户余额不足，请充值后重试。",
      "data": null
    }

  - 失败响应 (如：验证码错误或过期, HTTP 400):
    {
      "success": false,
      "message": "验证登录失败，请核对手机号和验证码后重试。",
      "data": null
    }
