# 小改 2026-07-23

## 1. 修改范围

本次修改围绕本地后台的标记业务迁移、平台菜单、账户充值、接口管理和平台编码整理展开。

当前系统中的以下三个一级业务模块保持独立：

1. 号码查询
2. 免费查询设置
3. 标记业务管理

本次没有把三个模块合并为一个项目，也没有删除号码查询和免费查询原有业务。

## 4. 平台编码调整

### 4.1 搜狗

- 账户充值平台选项
- 标记订单、价格、余量和钱包流水迁移语句

号码查询、免费查询、批量查询等旧业务中的外部字段不在本次修改范围内，没有强制修改。

### 4.2 360

标记业务范围内，360 编码已从 `sanliuling` 修改为 `360fugai`。

已同步修改：

- 用户端 360 菜单路径和查询参数

前端内部仍保留兼容性的路由标识 `sanliulingMark`，该标识不会作为平台编码提交到后端。

## 5. 账户充值

用户管理中的“充值/扣减”入口已调整为“账户充值”。

账户充值页面按平台展示：

- 平台名称
- 平台编码
- 平台状态
- 单价
- 剩余次数
- 充值操作
- 扣减操作

充值和扣减使用标记业务平台编码，并与用户平台余量数据关联。

## 6. 标记接口管理

标记业务管理下新增独立菜单“接口管理”。

页面功能包括：

- 按 API 名称查询
- 按绑定平台编码查询
- 按启用/禁用状态筛选
- 新增接口
- 编辑接口
- 切换接口状态并二次确认
- 测试连接
- 删除接口
- 通过下拉框绑定代理处理平台

API 名称作为固定名称保存；编辑时主要修改绑定平台、接口地址、状态、超时和重试配置。

## 7. 三个业务模块的菜单拆分

迁移过程中曾复用号码查询的“平台API配置”菜单记录，导致号码查询入口消失。现已拆分为独立菜单：

| 一级模块 | 菜单 | 前端组件 |
| --- | --- | --- |
| 号码查询 | 平台API配置 | `server/numberPlatformConfig/index` |
| 免费查询设置 | API接口 | `server/freeQuerySettings/api/index` |
| 标记业务管理 | 接口管理 | `server/platformConfig/index` |

号码查询的原平台 API 配置界面已恢复，标记业务使用新的菜单 ID，不再移动或覆盖号码查询的菜单记录。
