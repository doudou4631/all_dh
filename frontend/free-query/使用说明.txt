# 号码标记查询平台

## 使用方法

1. 双击 `启动本地预览.bat`
2. 浏览器会自动打开本地页面  
   或手动访问：http://127.0.0.1:18765/#/

> 不要直接双击 `index1.html`（file:// 协议下绝对路径 `/static/...` 无法加载）。必须通过本地服务打开。

## 说明

- 页面 HTML、CSS、JS、字体和平台图标均从本地加载
- `server.py` 将 `/h5` 查询请求适配到本项目后端 `/server/freeQuery/single`
- 未提供的接口和缺失的静态文件直接返回错误，不访问原站

## 上线安全要求

- 生产环境必须同时为 Java 后端和 `server.py` 设置相同的 `FREE_QUERY_INTERNAL_KEY`，不要使用项目内的开发默认值
- 生产环境必须单独设置 `FREE_QUERY_SIGNING_KEY`，用于一次性查询令牌签名，不要与代理密钥相同
- Java 后端 8080 端口只监听 `127.0.0.1`，不要通过路由器、防火墙或公网代理直接暴露
- 对外反向代理只发布免费查询页面，并使用 `X-Real-IP` 覆盖写入真实客户端 IP；不要透传客户端提交的该请求头
- 后台跨域域名通过 `CORS_ALLOWED_ORIGIN_PATTERNS` 配置，生产环境只填写实际管理端域名
- 可通过 `FREE_QUERY_MAX_CONCURRENT` 调整查询最大并发数，默认值为 8
- 一次性查询令牌默认 90 秒有效，可通过 `FREE_QUERY_TOKEN_TTL_SECONDS` 调整；这不会改变结果显示延时
- 当前令牌消费和多维限流使用单实例内存状态；部署多个 Java 后端实例时必须改用共享 Redis
